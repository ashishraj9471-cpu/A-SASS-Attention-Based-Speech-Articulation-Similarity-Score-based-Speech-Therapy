# A-SASS: Attention-Based Speech Articulation Similarity Score for Speech Therapy

A-SASS is an AI-based speech therapy framework designed to assess
speech articulation similarity using attention-based speech analysis
and video reenactment.

## Overview

The proposed system provides a computer-assisted speech therapy
framework that compares patient speech/articulation with therapist
reference speech and visual articulation patterns.

The system integrates:

- Speech analysis
- Articulation similarity assessment
- Attention-based feature extraction
- Facial feature analysis
- Phoneme-level analysis
- Therapy session management
- Streamlit-based user interface



## Features

- Streamlit-based speech therapy interface
- Patient reference input
- Therapist reference input
- Video reenactment
- Facial feature extraction
- Phoneme analysis
- Articulation similarity scoring
- Session management
- Therapy dashboard
